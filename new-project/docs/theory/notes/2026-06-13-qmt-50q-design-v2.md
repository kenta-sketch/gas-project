# QMT 50問診断 v2.0 完全設計書

QMT理論第10版(2026-06-13受領)を起点に、これまでの実装・実証・議論をすべて統合した50問体系。
**v1.0(75問)よりも質問数を減らしながら、本質をより深く探る** ことを目標とする。

---

## 0. 設計思想(なぜ50問か・何を測るか)

### 0.1 v1.0(75問)から削った理由
- 75問は項目重複が多く、特に C軸質問が冗長(122人実証で SD=1.18 と最低の弁別力)
- 「自分は直感がある」全員肯定で識別不能の質問群を整理
- 50問なら 15-20分で完了でき、回答疲労による後半質問の劣化を防げる

### 0.2 第10版で追加される測定対象
| 概念 | v1.0 | v2.0 で新規 |
|---|---|---|
| A内的 / A表出 分離 | ✓ | ✓ 維持 |
| B内的 / B表出 分離 | (G2で間接) | ★ 明示的分離 |
| **B由来C**(対人直観の核心) | 未測定 | ★ 4問専用 |
| ACTT(A/B葛藤・拮抗状態) | 未測定 | ★ 葛藤状態の有無を測る |
| **エンジン同盟**(B×D / A×C / B×C / A×B) | 未測定 | ★ 各2問、計8問 |
| Observer 3段階(事後→途中→事前) | 部分 | ★ 段階別質問 |
| 過剰Observer(Overdrive) | 未測定 | ★ 行動コスト測定 |
| Platform層(身体・睡眠) | 未測定 | ★ 2問 |
| 沈黙の五類型(A凍結/A抑圧/C/D/Obs) | 部分 | 統合判定で識別 |

### 0.3 122人実証から学んだ設計原則
- **C軸質問は領域特定**(汎用ではなく「営業の場面で」など)
- **A/B は内外分離必須**(発火と表出を別問で測る)
- **C-D 相関 +0.37 を意識**(C問とD問の文言が似すぎないよう注意)
- **「4ばかり選ぶ」同意傾向バイアスを変数化**(Response Style第2層で吸収)
- **質問の弁別力(SD)で重み配分**(SD<1.2 の質問は重み軽減)

### 0.4 1〜5回答の "裏読み" 共通フレーム

| 値 | 表面の意味 | 構造的な裏側 |
|---|---|---|
| **1** | 「全くあてはまらない」 | 確信的否定。**または**極端型バイアス(1か5しか使わない人)。逆転項目では「明確に否定する内的反応」 |
| **2** | 「あまりあてはまらない」 | **穏当型バイアス**(2-4のみ使う人)の中の否定寄り。識別型なら本物の弱い否定 |
| **3** | 「どちらでもない」 | **4種類の意味**:①真の中立、②**解離・無感覚**(A凍結の指標)、③**回避**(質問が刺さって考えたくない)、④**わからない**(自己観察不足)。**Neutral Frequency 高フラグ**で他指標と組み合わせて判別 |
| **4** | 「ややあてはまる」 | 122人で **32.7%が選ぶ最多値=同意バイアス**。穏当型かつポジティブ自己呈示。Response Style Profile で補正 |
| **5** | 「とてもあてはまる」 | 確信的肯定。**または**極端型バイアス。逆転項目では「明確に肯定する内的反応」 |

加えて、**回答時間**を全質問で計測:
- 即答(<3秒): 確信または **思考停止**
- 通常(3-12秒): 自然な内省
- 長考(>12秒): 葛藤・回避・自己観察の深さ。**ACTT葛藤状態の指標**

## 1. 質問体系(全50問)

### Group 1: コア4エンジン × 内外分離(28問)

#### 1.1 A: 動物的感情(7問)

A は「無人島でも生じる感情か」(他者の存在に依存しない一次反応)。
内的発火と外的表出を必ず分離する。**「感情表現が少ない=Aが低い」は最も危険な誤判定**。

| ID | 質問 | 測定 | 1の裏側 | 5の裏側 | 逆転 |
|---|---|---|---|---|---|
| **A-1** | 嫌なことがあったとき、理由を考える前にまず身体が反応する(胸が締まる/動悸/熱くなる など) | A内的(発火強度) | 身体反応の鈍化・凍結の可能性 | 強いA発火が日常で起きる | |
| **A-2** | 危険や違和感を、論理より先に感覚として察知する | A内的 / C(身体由来) | A鈍麻 or 切断 | A発火が判断材料 | |
| **A-3** | 誰もいない場所で、好きなものに触れたとき内側が強く動く | A内的(無人島テスト) | A低 or 凍結 | A発火生きている | |
| **A-4** | 嬉しいとき、その場で素直に「嬉しい」と表現できる | A表出(出力強度) | 表出抑制(抑圧型/凍結型) | A表出が自然 | |
| **A-5** | 嫌だと感じたことを、相手にそのまま「嫌だ」と伝えられる | A表出 | B優位の典型値(承認依存) | A優先・自律性高 | |
| **A-6** | 一人ならできるが人前ではできない感情表現がある | **A抑圧判定** | 抑圧なし or 凍結で内的Aが弱い | A抑圧型(火山型)の典型 | |
| **A-7** | 後から「本当はこう言いたかった」と思うことが多い | **A抑圧の蓄積指標** | 言えている or 内的A低 | A抑圧型・燃え尽きリスク | |

**注**: A-6, A-7 が「抑圧判定の核心」。A-1〜A-3 で内的A高、A-4〜A-5 が低、A-6〜A-7 で高なら **A抑圧型(火山型)** と確定。
内的A低かつ表出A低なら **真性A低 or A凍結型**(後者は身体質問で判別)。

#### 1.2 B: 機械的感情(承認・恥・社会的同調)(6問)

| ID | 質問 | 測定 | 1の裏側 | 5の裏側 | 逆転 |
|---|---|---|---|---|---|
| **B-1** | 他人にどう思われているかが頭から離れない時間がある | B内的(反応強度) | B独立型 or B解離 | B高感度・反芻傾向 | |
| **B-2** | 「期待されている」と感じると、それに応えなければというプレッシャーが強くなる | B内的 | B独立 | B型責任感の核 | |
| **B-3** | 拒絶・否定されると、その後しばらく内側で引っかかり続ける | B内的 / 反芻 | レジリエンス高 or 解離 | SFNE的なB高 | |
| **B-4** | 嫌われたくなくて断れないことがある | B表出(影響強度) | 自律性高 | 承認依存型の典型 | |
| **B-5** | 場の空気を壊さないように自分の発言や行動を調整する | B表出 | 独立行動型(A優位 or D優位) | B表出・適応性高 | |
| **B-6** | 周囲の反応によって意思決定が変わることがある | B表出・意思決定への影響 | 軸ぶれない | B依存度高 | |

**B内外分離の意味**: 「B内的高 × B表出低」= 隠れ消耗型(★現場で誤読最多)。気にしているのに表に出さず燃え尽きる。
「B内的低 × B表出高」= 適応型(社会的演技)。スキルとしてのB。

#### 1.3 C: 動物的理性(経験圧縮による予測)(5問)

**重要**: C は領域特定必須(汎用「直感がある」は全員肯定で SD=1.02)。
回答時に「あなたの主な仕事領域(営業/技術/管理/対人支援 など)」を最初に選択させ、その領域の C を測る。

| ID | 質問 | 測定 | 1の裏側 | 5の裏側 | 逆転 |
|---|---|---|---|---|---|
| **C-1** | (選択した職務領域で)言語化できないが「これは行ける/危ない」と分かる瞬間がある | C(領域特定) | 経験不足 or D優位検証派 | C高(熟達直観) | |
| **C-2** | (同じ領域で)5年前なら気づかなかった微細なシグナルに今は気づける | C成長(時系列直観) | 熟達進んでいない | 経験圧縮継続中 | |
| **C-3** | 「なぜそう判断したか」を後から言葉にしようとすると上手く説明できない | C特性(言語化以前) | D由来Cで言語化可能 | 純粋C(言語遮蔽の予兆) | |
| **C-4** | 過去の似た失敗経験が、瞬間的に判断を助けることがある | A由来C・B由来C(経験記憶) | 経験未活用 | 経験圧縮機能している | |
| **C-5** | 専門外の領域では、自分の直感が当てにならないと自覚している | **C領域特定の自己認識**(逆認識) | C過信(汎用思い込み) | C領域限定の正しい理解 | |

**C-5は重要**: C高でC-5低=「自分はどの領域でも直感が当たる」と思っている人は **C思い込み・属人化リスク**。

#### 1.4 D: 機械的理性(論理・構造化・翻訳)(5問)

| ID | 質問 | 測定 | 1の裏側 | 5の裏側 | 逆転 |
|---|---|---|---|---|---|
| **D-1** | 判断する前に、目的と基準を言語化したくなる | D(コア) | C単独運転 or D無関心 | D高(設計型) | |
| **D-2** | 自分の判断理由を、他者に分かるように説明できる | D(翻訳機能) | 言語化困難(C高D低の典型) | D機能している | |
| **D-3** | 成功パターンを言葉で残すことを習慣にしている | D(再現性志向) | 暗黙知派 | D由来Cへの蓄積 | |
| **D-4** | 感情が動いた直後でも、論理的に整理してから動ける | D × Observer | D低 or A単独運転 | D介入機能 | |
| **D-5** | 「考えすぎて動けない」状態に陥ることがある | **過剰D / 過剰Observer の予兆** | 行動コスト低 | D単独運転 or Overdrive | |

#### 1.5 B由来C(★第10版の核心独自概念)(5問)

「この人は今本音を言っていない」「この場の空気は危ない」など、**社会的感情経験の蓄積から生まれる対人直観**。
A由来C(身体記憶)や D由来C(分析熟達)とは別経路の C。

| ID | 質問 | 測定 | 1の裏側 | 5の裏側 | 逆転 |
|---|---|---|---|---|---|
| **BC-1** | 相手が「大丈夫」と言っていても、大丈夫じゃないと察知できる | B由来C(本音察知) | B経験不足 or B解離 | B由来C高 | |
| **BC-2** | 初対面で「この人は信頼できる/危ない」を感じ取り、後で当たることが多い | B由来C(対人初見) | 経験浅い or 過信 | B由来C成熟 | |
| **BC-3** | 場が変な空気になる前に、その兆しを感じる | B由来C(空気) | 集団場面の経験少 | B由来C・場の予測 | |
| **BC-4** | 過去に拒絶・裏切りを経験し、それを今の対人判断に活かしている | B由来C(修復経験) | 修復未経験 or 経験回避 | 修復ありB由来C柔軟 | |
| **BC-5** | 「人は必ず裏切る」「結局みんな自分のことしか考えない」と感じることがある | **B由来C歪曲フラグ**(トラウマ起源) | 健全 | C歪み(過去Bトラウマの固定化) | |

**BC-5は逆指標**: 高得点 = B由来Cが歪んでいる可能性(現場で最も誤読される)。

### Group 2: Observer + 統合状態(7問)

Observer は A/B/C/D を上位から認識・介入する Meta層。3段階発達(事後→途中→事前)。

| ID | 質問 | 測定 | 1の裏側 | 5の裏側 | 逆転 |
|---|---|---|---|---|---|
| **OB-1** | 感情で動いた後で「あの時感情で動いていた」と気づくことがある | Observer Lv.1(事後) | 未起動 or 解離 | 最低限のObserver | |
| **OB-2** | 感情が動いている最中に「今これに反応している」と認識できることがある | Observer Lv.2(途中) | 未到達 | 途中介入可能 | |
| **OB-3** | 強い感情が湧きそうなとき、湧く前に予測してブレーキをかけられる | Observer Lv.3(事前) | 未到達 | 統合方向 | |
| **OB-4** | 「分かっているのにできない」状態を経験することがある | Observer起動 × エンジン優勢 | Observer未起動 or 完全制御 | Observer起動・出力差問題 | |
| **OB-5** | 衝動的に動きそうな時、一瞬止まれることがある | Veto力(自由意志機能) | 未起動 | Veto機能 | |
| **OD-1** | すべての感情・行動に対して自分を監視する癖があり、それで動きが鈍ることがある | **過剰Observer(Overdrive)** | 適度 | Overdrive(逆U字の右側) | |
| **OD-2** | 何かを決めるとき、選択肢を見すぎて決められなくなることがある | 過剰Observer / 過剰D | 行動コスト低 | Overdrive・分析麻痺 | |

**統合判定**: OB-3 高 + OD-1, OD-2 低 = 統合状態 Lv.3。
OB-1 だけ高 = Lv.1(事後気づき) で発展途上。
OD-1, OD-2 だけ高 = 過剰Observer(統合状態とは別)。

## 2. 採点ロジック(v2.0)

### 2.1 軸スコア(0-25点に正規化)

```
A内的 = (A-1 + A-2 + A-3) / 3 * 5     # 3問・25点満点
A表出 = (A-4 + A-5) / 2 * 5            # 2問
A抑圧指標 = A-6 + A-7                  # 0-10点

B内的 = (B-1 + B-2 + B-3) / 3 * 5
B表出 = (B-4 + B-5 + B-6) / 3 * 5

C(領域特定) = (C-1 + C-2 + C-3 + C-4 - C-5の反転補正) / 4 * 5
B由来C = (BC-1 + BC-2 + BC-3 + BC-4) / 4 * 5
B由来C歪曲度 = BC-5

D = (D-1 + D-2 + D-3 + D-4) / 4 * 5
D過剰指標 = D-5
```

### 2.2 Observer + 統合状態

```
Observer Lv.1 = OB-1
Observer Lv.2 = OB-2
Observer Lv.3 = OB-3
Observer統合 = max(Lv.1, Lv.2, Lv.3) - min(分布偏り補正)
Veto力 = OB-5

過剰Observer = (OD-1 + OD-2) / 2
過剰Observer フラグ = 過剰Observer >= 4 AND Observer統合 >= 4
                  (= Overdriveの逆U字右側)
```

### 2.3 エンジン同盟検出

```
B×D同盟強度 = (AL-BD1 + AL-BD2) / 2
A×C同盟強度 = (AL-AC1 + AL-AC2) / 2
B×C同盟強度 = (AL-BC1 + AL-BC2) / 2
A×B同盟強度 = (AL-AB1 + AL-AB2) / 2

同盟フラグ: 強度 >= 4 で該当同盟「形成」
```

### 2.4 タイプ判定(v1.0の12タイプを継承 + 同盟タイプ追加)

判定優先順位:
1. **A凍結型** (FZ-1高 + 内的A低 + PL劣化)
2. **A抑圧型** (内的A高 + 表出A低 + A-6,7高)
3. **過剰Observer型** (OD-1,2 高 + 行動停止)
4. **エンジン同盟型** (いずれかの同盟強度 >=4)
   - B×D型 (正しさの檻)
   - A×C型 (天才の暴走)
   - B×C型 (空気の独裁)
   - A×B型 (承認の炎)
5. **統合型** (Observer Lv.3 高 + 全軸均衡)
6. **単独運転型** (一軸突出 + Observer低)
7. **主軸+副軸の組合せ** (突破/共感/設計/忠実/直感/分析/蓄積)

### 2.5 第2層変数(v1.0から継承)

- Response Style Profile(穏当/識別/極端/中立/同意/否定)
- Neutral Frequency(3選択率、>30%でフラグ)
- 軸間相関補正(C-D=0.37 等を反映、122人実証から)
- **回答時間プロファイル**(全質問計測):
  - 即断型(<3秒/問): 確信 or 思考停止
  - 慎重型(>12秒/問): 葛藤・自己観察
  - 質問IDごとの長考フラグ → ACTT葛藤状態の指標

### BC-1「相手が大丈夫と言っていても、大丈夫じゃないと察知できる」(重み2.0)

| 値 | 表面 | 裏側 |

| 1 | できない | **B経験不足** or **B解離**(他者に関心が向いていない)。前者なら成長余地、後者なら関係構築自体への抵抗 |
| 2 | あまりできない | 穏当型かつ、対人感度の発達途上 |
| 3 | わからない | B由来Cが未確立 or 自分のB由来Cを観察できていない |
